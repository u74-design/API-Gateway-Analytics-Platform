
**API Gateway & Analytics Platform**

Developed a full-stack API Gateway and Analytics Platform that enables users to register external APIs, generate secure proxy endpoints and API keys, apply dynamic rate limiting, enable Upstash Redis-based response caching, and monitor API usage through real-time analytics dashboards.

Implemented JWT authentication, API key validation, reverse proxy request forwarding, Upstash Redis-powered rate limiting with configurable time windows, response caching, and detailed analytics tracking. Built analytics features including request history, blocked request monitoring, cache hit tracking, average latency calculation, and dashboard statistics. The platform uses Node.js, Express.js, MongoDB Atlas, Upstash Redis, and React to provide a scalable, production-style API management solution inspired by AWS API Gateway, Kong, and Apigee.
